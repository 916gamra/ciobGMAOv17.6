# Changelog: BDR Nexus (GMAO v17.6)

All notable changes to this project will be documented in this file.

## [17.6.0] - 2026-08-09
### Added
- Real-time Sync Engine & Offline-first Dexie DB persistence.
- Advanced Predictive Maintenance engine and Analytics Dashboard.
- Strict 4-Dimension data architecture (Template, Blueprint, Stock Instance, Machine).
- 999 Slots Rule with sequential nomenclature and PDR Engine integration.
- Layered Glass Architecture & Unified Neutral Base UI standards.

## [1.0.1] - 2026-05-02
### Changed
- Refined OS Navigation:
  - Moved `Persistent Tab Bar` to high Z-index top positioning.
  - Implemented `Fixed Sidebar` to maintain consistency across all modules.
  - Resolved UI layering and padding conflicts for tab placement.
- Dock Improvements:
  - Fixed issue where workspace menu remained open after mouse-out.
  - Optimized menu closing behavior and interaction logic.
- Developer Documentation:
  - Updated project state and provided initial changelog structure.
